# AIPayPerCrawl

Content and static site for an AI pay-per-crawl licensing concept: 240 Markdown articles on crawler detection, robots.txt policy, licensing endpoints, and bot management, plus the static pages and build scripts that publish them.

## Contents

- `Articles/` — the article sources in Markdown.
- `dist/` — built HTML output.
- `scripts/` — the build and publishing helpers.

Unverified launch copy, client-result claims, and unresolved editorial markers were removed from the public archive.

## History

This repository was rebuilt from its final working tree on 2026.07.25 with a single commit. The prior commit history was retired because it contained credential-shaped test material and local environment paths. Nothing in the published content changed apart from removing a local filesystem path from one article's closing section.

## How this was built

Article drafting and site assembly used model assistance under human direction and review. Code samples use short `DEMO` values or runtime environment variables; they do not contain working credentials.
